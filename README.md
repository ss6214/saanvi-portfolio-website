# Saanvi Shankar Portfolio Website

A dashboard-style personal portfolio site for Saanvi Shankar, built as a static HTML/CSS/JavaScript project.

## Sections

- Dashboard-style hero with role, focus areas, and skill radar
- Experience timeline based on the resume
- Selected project cards with visual analytics elements
- Skills stack organized by data engineering, databases, visualization, cloud, and DevOps
- Contact and resume links

## Run Locally

Open `index.html` in a browser, or serve the folder with:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Publish

This can be published with GitHub Pages by pushing this folder to a repository and enabling Pages from the `main` branch.
